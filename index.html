À propos

Je suis finissant du DEC en Techniques de l'informatique (réseautique) au Collège de Rosemont. J'ai une expérience concrète en téléphonie IP et en environnement de centre de données.

Ce que j'aime, c'est comprendre comment les choses sont connectées — du câblage physique d'un routeur Cisco jusqu'au montage d'un serveur téléphonique qui relie deux réseaux distants. Je documente mon travail sous forme de runbooks reproductibles, parce qu'une installation qu'on ne peut pas reproduire n'est faite qu'à moitié.

Je vise le poste de technicien en télécommunication : installation et réparation des services de téléphonie, d'internet et de fibre. Disponible et flexible, permis Classe 5.

Technical Runbooks — procédures de soutien TI

Chaque modification est vérifiée par GitHub Actions (markdownlint, liens, PSScriptAnalyzer).

Helpdesk Toolkit — module PowerShell de diagnostic

public · v1.0.0 · MIT

Module PowerShell compatible Windows PowerShell 5.1 qui automatise les premières minutes d'un billet de soutien. Six commandes : rapport système (version de Windows, numéro de série, mémoire, disques, temps de fonctionnement), diagnostic réseau couche par couche avec la cause probable, inventaire des logiciels lu dans le registre, santé des disques, nettoyage des fichiers temporaires avec aperçu -WhatIf, et rapport HTML autonome à joindre au billet. Testé avec Pester sous PowerShell 5.1 et 7, analysé par PSScriptAnalyzer.

  • PowerShell 5.1
  • Pester
  • PSScriptAnalyzer
  • CIM / WMI
  • HTML
  • GitHub Actions

Homelab Infrastructure — documentation anonymisée

public · Linux · ADR

Documentation publique d'une petite infrastructure personnelle : deux serveurs Ubuntu et un poste d'administration reliés par un VPN maillé basé sur WireGuard, sans aucun port d'administration public. Chaque choix important est expliqué dans un ADR (contexte, décision, coût, options rejetées) : cloisonnement des rôles, ports Docker publiés sur 127.0.0.1, surveillance d'un serveur par l'autre. Côté code : un script de veille croisée qui n'alerte qu'une fois par panne, un relais de messagerie en Python (bibliothèque standard seulement) avec ses tests unitaires et une unité systemd durcie expliquée ligne par ligne. Le dépôt contient aussi le plan de sauvegarde et de reprise, un plan de retour en arrière et les leçons apprises. Un contrôle automatique bloque toute vraie adresse, clé ou jeton.

  • Ubuntu Server
  • WireGuard
  • ufw
  • Docker
  • Bash
  • Python
  • systemd
  • ShellCheck

Durcissement CIS Benchmark — Ubuntu et Windows 11

cours · 420-H34 · scripts

Deux scripts, en Bash pour Ubuntu 24.04 et en PowerShell pour Windows 11, qui appliquent des règles du CIS Benchmark décrites dans un fichier XML. Le mode validation (-v) vérifie la conformité sans rien modifier ; le mode correction (-c) corrige les écarts avec les droits d'administrateur. Les scripts sont vérifiés automatiquement par ShellCheck et PSScriptAnalyzer, et chacun a son guide d'utilisation.

  • CIS Benchmark
  • Bash
  • PowerShell
  • XML
  • ShellCheck
  • PSScriptAnalyzer

Services Internet sur AWS & Terraform

En équipe, déploiement et supervision de services sur EC2 : GLPI, Nextcloud avec stockage S3, Mattermost avec base RDS PostgreSQL, Jellyfin suivi par des tableaux de bord et alarmes CloudWatch.
